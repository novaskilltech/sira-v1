# Dossiers de validation éditoriale

Les fichiers JSON de ce dossier sont générés depuis les inventaires gelés avec `npm run editorial:prepare`.

- `fiches.v1.json` : 60 dossiers de récit à documenter et faire valider.
- `narrations.v1.json` : 120 scripts et pistes, initialement sans texte ni fichier audio.
- `assets.v1.json` : 45 illustrations, 14 animations, 20 GLB et 20 fallbacks à produire et examiner.
- `objets-3d.v1.json` : choix de reconstitution, fichiers éditables, droits et tests appareil.
- `publication-readiness.v1.json` : comptage et blocages de publication.

Ils sont intentionnellement `NON_VALIDE`. Seuls des relecteurs indépendants peuvent renseigner une preuve et une décision d'approbation ; le manifeste public et son gate restent l'autorité de publication.
